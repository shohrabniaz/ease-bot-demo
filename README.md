# EASE-Bot demo

This repository exists to show [EASE-Bot](https://github.com/shohrabniaz/ease-bot) working on a real
pull request. The files in the demo PR are **deliberately insecure** (public S3 ACL, unencrypted EBS
volume, SSH open to the internet, a privileged container on the host network). Do not deploy them.

Open the pull requests tab to see the bot's suggested changes and summary comment.
